# 백스테이지 크루 — 모바일 프로토타입

기획서의 「모바일 프로토타입 사양」을 구현한 그레이박스 웹 게임입니다. 횡스크롤부 스테이지 1개, 1인 플레이(약 3분).

## 실행

```bash
npm install
npm run dev        # 같은 Wi‑Fi의 휴대폰에서 표시되는 Network 주소로 접속
npm run build      # dist/ 에 정적 파일 생성 (아무 정적 호스팅에 올리면 됨)
npm run artifact   # artifact/backstage-crew.html 단일 파일 생성
```

휴대폰은 **가로 화면**으로 플레이합니다.

| 모드 | 조작 |
| --- | --- |
| 1인 | 터치 / 키보드(방향키 · Space 점프 · J 집기 · K 작업(꾹) · L 위장) / 게임패드 |
| 2인 협동 | 한 폰을 양쪽에서 터치 / 1P: WASD · Space · E · Q · R, 2P: 방향키 · `/` · `.` · `,` · M (넘패드 0~3도 가능) / 게임패드 2개 (A 점프 · B 집기 · X 작업 · Y 위장) |

## 재미 요소 (2차 추가)

1. **게이지 충돌**: 대기실 문이 2층(카메라 층)으로 이동. 적을 넣으려면 들킬 위험을 감수해야 한다.
2. **아슬아슬 보너스**: 프레임이 닿기 0.6초 안에 위장하면 +150, 의심 70% 이상에서 빠져나오면 +200. 짧은 슬로모션과 화면 번쩍임이 들어간다.
3. **플레이어 AI 말풍선**: 동전, 빈 블록, 사망, 의심, 지루함 등 상황별 대사.
4. **상황에 맞는 위장**: 바닥의 하늘색 표시(소품 자리)에서 위장하면 그 구역 소품(덤불·구름·벽돌·화분)으로 완벽하게 숨는다. 아무 데서나 하면 '어색한 상자'가 되어 의심이 천천히 오른다.
5. **콤보**: 업무를 5초 안에 연달아 처리하면 배율이 오른다(100 × 콤보). 실수하거나 들키면 끊긴다.
6. **돌발 사건**: 크래시 습격(채워 둔 블록을 털어 감), 뒷걸음질(카메라가 뒤로), 스피드런(1.6배 속도). 두리번 이벤트와 번갈아 일어난다.
7. **2인 협동**: 동료 옆에서 [집기]를 누르면 패스, 스틱 ↑ + [집기]를 누르면 위층으로 던지기, 빈손이면 공중에서 받기.

그래픽은 8비트 콘솔 느낌의 제한 팔레트와 외곽선 도트 스프라이트(`src/sprites.ts`)로 다시 그렸다. 캐릭터와 소품은 모두 오리지널이다. 스태프가 카메라 프레임에 들어가면 모자이크로 '도트 변환'된다.

## 조정해 볼 값 (`src/level.ts`)

- `TASK_LEAD` = 6초 — 기획서의 “3초 전”은 창고 왕복이 불가능해서 6초로 늘렸습니다.
- `PLAYER_SPEED`, `PLAYER_SKILL`, `PLAYER_CURIOSITY`, 발판 초기 내구도, 블록/문 간격.
- 게이지 증감은 `src/game.ts`의 `hitBlock`, `updateGauges`, `updateTasks`에 모여 있습니다.
